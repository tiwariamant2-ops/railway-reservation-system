# 🚆 Railway Reservation System

A simple **Python-based Command-Line Railway Reservation System** that allows users to view trains, book tickets, check PNR status, and cancel reservations.

## 📌 Project Overview

The Railway Reservation System is a Python CLI application developed to simulate basic railway ticket reservation operations.

The system allows users to:

- View available trains
- Book train tickets
- Check PNR status
- Cancel tickets
- Automatically update seat availability
- Store train and booking information using JSON

The project demonstrates important Python programming concepts such as **Object-Oriented Programming, functions, dictionaries, loops, conditional statements, file handling, JSON, exception handling, and input validation.**

---

## ✨ Features

- 🚆 View available trains
- 🎫 Book a train ticket
- 🔎 Check PNR status
- ❌ Cancel a ticket
- 💺 Automatically update available seats
- 💾 Store data using JSON
- 🔢 Generate a random PNR number
- ✅ Validate passenger details
- 🛡️ Handle invalid inputs
- 📁 Automatically create the JSON database if it does not exist
